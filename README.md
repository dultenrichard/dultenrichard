# Website Reboot — Blank Slate

This branch is the **clean-room starting point** for a new personal website.

The previous site, its layouts, pages, stylesheets, scripts, templates, build pipeline, and earlier drafts are **not included** in this branch.

No existing UI pattern, visual direction, or page hierarchy is approved. The new experience will be decided and built from first principles.

The old `main` branch and earlier Git history are preserved as a reversible safety archive. This branch is not published and has no open pull request.

Current state: deliberate placeholder, not a finished design.
